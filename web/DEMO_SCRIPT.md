# JC-APEX Demo Script (60-second walkthrough)

## Pre-Demo Setup
1. Open browser to http://localhost:3000
2. Enable DEMO mode via passcode (if prompted)
3. Navigate to Pit Center

## Demo Script (60 seconds)

**0:00-0:10** - Landing Page
- Show hero section with animated telemetry demo
- Highlight F1-inspired design and "Pit Wall" aesthetic
- Click "Start Racing" to navigate to role selection

**0:10-0:15** - Role Selection
- Show three roles: Pit Engineer, Driver, Race Director
- Select "Pit Engineer" to enter Pit Center

**0:15-0:30** - Pit Center Overview
- Show telemetry KPI tiles with live data (speed, voltage, current, power, battery %, efficiency)
- Highlight color-coded status (green = nominal, amber = warning, red = critical)
- Show AI Oracle panel with real-time recommendations
- Show command history with ACK status

**0:30-0:40** - Command System
- Click "BOX THIS LAP" quick command
- Show command appears in command history
- Navigate to Driver HUD to show command delivery

**0:40-0:50** - Driver HUD
- Show large speedometer with target pace light bar
- Show flag overlay (simulate yellow flag change)
- Show strategy overlay (simulate strategy change)
- Show focus mode toggle
- Demonstrate command overlay with F1 styling

**0:50-0:60** - Back to Pit Center
- Navigate back to Pit Center
- Show command ACK received
- Show telemetry chart with live data
- Highlight signal quality and GPS lock status

## Demo Mode Features
- Simulated lap pattern with realistic noise
- GPS dropout event at 30 seconds
- Low-battery event at 45 seconds
- Flag change event at 50 seconds
- All features work with zero hardware and zero internet
